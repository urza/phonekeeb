    The pad is deliberately blank. Knowing which loop to draw is the hard part of this keyboard, and a visible map practises the easy part instead. Miss one and it comes back soon; get it right and it waits longer. Ring 1 is eight letters and covers most typing, so the next ring unlocks only once these are solid.
